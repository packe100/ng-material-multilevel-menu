# ng-mat-multilevel-menu
Material Multi-Level Menu for Angular projects, compatible with Angular version up to 19.

This project is a fork of the original ng-material-multilevel-menu, that you can find [here](https://www.npmjs.com/package/ng-material-multilevel-menu) for detailed documentation.
The fork was necessary for lack of support for Angular 19/20 of the original project.

## Installation
```npm install --save ng-mat-multilevel-menu```
